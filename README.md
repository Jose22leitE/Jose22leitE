## 🚀 Sobre mí

¡Hola! Soy **José Gabriel Leite**, TSU en Informática y estudiante de Ingeniería en Informática. Me apasiona crear software moderno, configurar redes y construir flujos de automatización inteligentes con Inteligencia Artificial.
